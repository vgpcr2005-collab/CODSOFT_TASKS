# Sales Prediction Using Python

## CodSoft Data Science Internship - Task 4

This project focuses on predicting product sales using advertising expenditure.

## Objective

The objective is to build a machine learning model that predicts sales based on advertising spending on TV, Radio, and Newspaper.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Workflow

1. Load the dataset
2. Explore the dataset
3. Check missing values
4. Perform data analysis
5. Visualize the data
6. Select features
7. Split the data
8. Train the machine learning model
9. Make predictions
10. Evaluate the model

## Machine Learning

Regression models will be used to predict sales.

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Result

Model performance will be added after training and evaluation.
