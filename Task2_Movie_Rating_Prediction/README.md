# Movie Rating Prediction with Python

## CodSoft Data Science Internship - Task 2

This project focuses on predicting movie ratings using machine learning.

## Objective

The objective is to build a machine learning model that predicts movie ratings based on available movie information.

## Project Workflow

1. Load the movie dataset
2. Explore the dataset
3. Clean the data
4. Handle missing values
5. Perform data analysis
6. Select relevant features
7. Prepare the data for machine learning
8. Split the data into training and testing sets
9. Train the machine learning model
10. Make predictions
11. Evaluate the model

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

Model performance will be added after training and evaluation.
