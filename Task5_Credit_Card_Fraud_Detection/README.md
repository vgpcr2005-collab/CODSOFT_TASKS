# Credit Card Fraud Detection

## CodSoft Data Science Internship - Task 5

This project focuses on detecting fraudulent credit card transactions using machine learning.

## Objective

The objective is to build a machine learning model that classifies credit card transactions as legitimate or fraudulent.

## Project Workflow

1. Load the dataset
2. Explore the dataset
3. Check missing values
4. Analyze class distribution
5. Prepare the data
6. Handle class imbalance
7. Split the data
8. Train the machine learning model
9. Make predictions
10. Evaluate the model

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Machine Learning

A classification model will be used to identify fraudulent transactions.

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

Model performance will be added after training and evaluation.
