# Iris Flower Classification

## CodSoft Data Science Internship - Task 3

This project focuses on classifying Iris flowers into different species using machine learning.

## Objective

The objective of this project is to develop a machine learning model that can classify Iris flowers based on their sepal and petal measurements.

## Iris Species

The dataset contains three species:

- Setosa
- Versicolor
- Virginica

## Features

The model uses the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
